# 주식 전쟁 (stock-war)

삼성전자(005930) 주가를 3D 저폴리 전장으로 보여주는 관전형 시각화.
보는 사람이 남긴 한마디는 관중이 대신 외친다.
**홍군(빨강) = 매수 세력**, **청군(파랑) = 매도 세력**.

## 실행

```bash
python server.py
```

http://localhost:8000 — 별도 설치·빌드 없음. Three.js와 웹폰트는 CDN에서 받으므로 인터넷은 필요하다.

## 실데이터 연결

키만 주면 목업 대신 실데이터를 쓴다. **키움증권**과 **한국투자증권** 둘 다 붙는다.
어느 쪽을 쓰든 `/api/state` 스키마가 같아 프론트는 출처를 모른다. 코드 수정은 없다.
`.env.example`을 `.env`로 복사한 뒤 발급받은 키를 채우면 된다 — `.env`는
`.gitignore`에 있어 커밋되지 않는다.

```bash
cp .env.example .env   # 편집기로 열어 KIS_APP_KEY / KIS_APP_SECRET 채우기
python server.py
```

셸에서 직접 줘도 된다. 이때 셸 값이 `.env`보다 우선한다.

```bash
KIS_APP_KEY=... KIS_APP_SECRET=... KIS_ENV=vts python server.py
```

키를 채운 쪽이 자동 선택된다(둘 다 있으면 키움 우선). `STOCK_WAR_PROVIDER=kiwoom|kis`
로 명시할 수도 있다.

| 증권사 | 키 | 환경 | 발급처 |
| --- | --- | --- | --- |
| 키움 | `KIWOOM_APP_KEY` / `KIWOOM_SECRET_KEY` | `KIWOOM_ENV` = `demo`(기본) / `real` | [openapi.kiwoom.com](https://openapi.kiwoom.com/) |
| 한투 | `KIS_APP_KEY` / `KIS_APP_SECRET` | `KIS_ENV` = `vts`(기본) / `prod` | [apiportal.koreainvestment.com](https://apiportal.koreainvestment.com/) |

`STOCK_WAR_SYMBOL`, `STOCK_WAR_NAME` 으로 종목을 바꾼다.

> 키움 **Open API+**(`C:\OpenAPI` 에 설치되는 OCX)는 이것과 **다른 물건**이다.
> 앱키 방식이 아니라 영웅문 로그인 창으로 인증하고 32비트 전용이라 여기 붙지 않는다.
> 필요한 건 위 표의 **REST API** 쪽이다.

쓰는 키움 엔드포인트는 셋이다.

| 용도 | api-id | URL |
| --- | --- | --- |
| 현재가·시가·고저·거래량 | `ka10001` | `/api/dostk/stkinfo` |
| 호가 10단계 | `ka10004` | `/api/dostk/mrkcond` |
| 투자자별 매수/매도 | `ka10059` | `/api/dostk/stkinfo` |

투자자별은 매수·매도를 따로 받아야 해서 두 번 부른다(`trde_tp` 1/2). 폴링당 총 4콜인데
응답을 8초 캐시하므로 탭을 여러 개 열어도 늘지 않는다.

키가 없으면 목업으로 돌고, 시작 로그에 `[MOCK]` / `[LIVE KIS]` 중 어느 쪽인지 찍힌다.
`/api/state` 한 번이 KIS를 세 번 부르므로 응답을 8초 캐시한다. 탭을 여러 개 열어도
상류 호출량은 그대로다.

쓰는 엔드포인트는 셋뿐이다.

| 용도 | 엔드포인트 | TR ID |
| --- | --- | --- |
| 현재가·등락률·거래량 | `inquire-price` | FHKST01010100 |
| 호가 잔량 10단계 | `inquire-asking-price-exp-ccn` | FHKST01010200 |
| 투자자별 수급 | `inquire-investor` | FHKST01010900 |

수급은 장중 잠정치(09:30 / 11:30 / 13:20 / 14:30)와 마감 확정치(15:40~)에만 갱신된다.
그 사이엔 값이 안 변하므로 병력 수도 그대로 유지된다. 조회 실패 시 병력만 0이 되고
시세·전선은 계속 돈다.

## 배포

**해외에서는 키움 API 에 닿지 않는다.** 인증도 본문도 없는 맨 요청조차 앱에 닿기
전에 앞단에서 끊긴다 — 키움이 만든 JSON 이 아니라 일반 웹서버의 400 HTML 이 돌아오고
`Server` 헤더조차 없다. IP 허용 목록은 앱 단 제어라 적용될 기회가 없으므로 **등록해도
달라지지 않는다.** Render 는 한국 리전이 없어 이 경로로는 올릴 수 없다. 저장소의
`render.yaml` 은 그때의 흔적이다.

그래서 **집에서 돌리고 터널로 연다.** 집 IP 는 이미 키움에 등록돼 있어 막힐 이유가
없고, 키가 이 컴퓨터 밖으로 나가지 않으며, 무료다.

> **실전 키는 절대 올리지 않는다.** 공개되는 화면이 실계좌 자격증명을 들고 있을
> 이유가 없다. 공개에는 **모의투자 키만** 쓴다. 모의투자 키는 실전 키와 별개로
> [openapi.kiwoom.com](https://openapi.kiwoom.com/) 에서 따로 발급받아야 한다.
> `STOCK_WAR_PUBLIC=1` 이면 실전 값(`KIWOOM_ENV=real`)으로는 서버가 아예 뜨지 않는다.

### 1. cloudflared 를 깐다

```powershell
winget install --id Cloudflare.cloudflared
```

### 2. 서버를 루프백에 띄운다

```powershell
$env:STOCK_WAR_PUBLIC="1"; $env:STOCK_WAR_BIND="127.0.0.1"
python -u server.py
```

`STOCK_WAR_PUBLIC=1` 은 실전 키 차단 가드를 켜고, `STOCK_WAR_BIND` 는 바인딩을
루프백으로 좁힌다. 터널은 루프백만 있으면 되므로 가드를 켜면서도 `0.0.0.0` 으로
집 네트워크에 노출할 이유가 없다.

### 3. 터널을 연다

```powershell
cloudflared tunnel --no-autoupdate --url http://127.0.0.1:8000
```

`https://….trycloudflare.com` 주소가 나온다. 계정도 도메인도 필요 없다. 대신
**터널을 다시 켤 때마다 주소가 바뀌고**, 컴퓨터가 꺼져 있으면 아무도 못 본다.
주소를 붙박이로 쓰려면 Cloudflare 계정과 도메인이 있어야 한다(named tunnel).

### 무엇이 밖으로 나가나

서버가 내보내는 것은 **`/`, `/war.js`, `/api/state`, `/api/symbols`, `/api/chat`,
`/api/health` 뿐**이다.
같은 폴더에 있어도 `.env` 나 토큰 파일은 404 다. 허용 목록 방식이라 경로를 꼬아도
뚫리지 않고, `test_server.py` 가 실제로 서버를 띄워 이를 검사한다.

`/api/state` 응답에는 시세·호가·수급과 전투 상태, 그리고 방금 들어온 채팅만
들어간다. `/api/health` 는 설정과 토큰 발급 여부만 알려 주고 키 값은 싣지 않는다
— 로컬과 같은 키인지 대조해야 할 때를 위해 되돌릴 수 없는 sha256 지문만 낸다.
키나 토큰은 어떤 경로로도 나가지 않는다.

### 알아둘 것

- 무료 플랜은 파일이 재시작마다 날아간다. 접근토큰 캐시(`.kiwoom_token.json`)도
  같이 사라져 깨어날 때마다 토큰을 새로 받는다. 키움은 잦은 재발급을 막으므로
  깨어나는 횟수가 많으면 실패할 수 있다.
- 종목 선택은 **모두에게 같이 적용된다.** 서버가 종목 하나를 들고 있는 구조라,
  누가 바꾸면 보고 있는 사람 전부의 화면이 바뀐다.
- 모의투자 서버(`mockapi.kiwoom.com`)도 이 프로젝트가 쓰는 세 엔드포인트를 모두
  제공한다. 현재가·호가 10단계·투자자별 수급이 실전과 같은 값으로 온다.

## 종목을 바꿔도 그대로 맞는 이유

전투 수치는 **전부 비율**이다. 거래량 절대값을 기준으로 삼으면 종목마다 상수를 다시
잡아야 하지만, 점유율과 상대 강도는 종목·가격대·시간대와 무관하다.

- **병력** = 그 주체의 수급 점유율 × 총 병력 규모 ÷ 병종 가중치.
  거래량이 100배 달라도 구성비가 같으면 같은 병력이 나온다(`test_server.py`가 검증).
- **전선** = `tanh(등락률 / 3)` — 등락률 자체가 이미 비율이다.
- **전투 강도** = 직전 폴링 체결량 ÷ 최근 평균의 2배. 절대량이 아니라 "평소 대비 몇 배".
- **호가 압력** = `(매수잔량 − 매도잔량) / 총잔량`.

## 데이터 → 전투 매핑

| 데이터 | 전장 표현 |
| --- | --- |
| 현재가 | **경계선 위치**. 땅 한가운데를 가르는 금빛 선과 말뚝이 전선이다 |
| 호가 잔량 합계 | **땅에 번지는 진영 빛**. 경계에서 가장 진하고 뒤로 갈수록 옅어진다 |
| 호가 10단계 `askp1~10` `bidp1~10` | **호가벽**. 전선 양옆에 선 계단형 토루. 잔량이 두꺼울수록 높다 |
| 당일 저가 / 고가 | **성벽 HP**(회복 안 됨) + 바닥의 **최대 진격선** |
| 시가 `stck_oprc` | 바닥의 **개전선**(금빛 가는 선) |
| 폴링 간 체결량 증분 | **전투 강도**. 불꽃·화살 양과 유닛 이동 속도 |
| 개인 `prsn_*` | **보병** — 칼을 치켜들었다 내려친다 |
| 연기금 `pefn_*` | **궁병** — 후방에서 전선으로 화살을 쏜다 |
| 외국인 `frgn_*` | **기병** — 측면에서 창을 찌른다 |
| 기관 `orgn_*` − 연기금 | **장군** — 군기를 세운 큰 유닛. 금색 무기 |

연기금은 기관계에 포함돼 있으므로 장군에서 빼서 궁병으로 따로 세운다.

### 전선의 자는 상한가/하한가다

**성과 성 사이가 곧 가격제한폭 60%p** 다. 중앙이 기준가(0%)이고 좌우로 ±30%,
양 끝의 성이 하한가와 상한가다.

| 주가 | 전선 |
| --- | --- |
| 기준가 (0%) | 한가운데 |
| 상한가 (+30%) | 청군 성 도달 → **함락** |
| 하한가 (−30%) | 홍군 성 도달 → **함락** |
| −7.8% | 홍군 성까지 거리의 26% 지점 |

선형이라 1% 움직이면 성까지의 1/30 만큼 간다. 하루 등락이 보통 ±3% 안쪽이니
전선은 대개 중앙 근처에서 논다. 그게 맞다 — 성이 걸릴 만큼 밀리는 건 그날 주가가
정말로 제한폭 근처까지 갔다는 뜻이어야 한다.

성벽도 같은 자를 쓴다. 당일 저가가 하한가에 닿아야 홍군 성벽이 0이 된다.

### 바닥에 그어진 선들

| 선 | 뜻 |
| --- | --- |
| 금빛 굵은 선 + 말뚝 | **현재가**. 전선이다 |
| 붉은 선 | 오늘 **고가** — 홍군이 최대로 밀어붙인 지점 |
| 푸른 선 | 오늘 **저가** — 청군이 최대로 밀어붙인 지점 |
| 금빛 가는 선 | 오늘 **시가** — 개전선 |
| 흙빛 선 2쌍 | **막사 위치**(중앙에서 10% / 20%) |

성벽이 깎인 이유가 바닥에 남는다. 붉은 선이 청군 성 가까이 가 있으면 그만큼
청군 성벽이 닳아 있다.

### 호가벽

매수 10단계는 홍군 쪽에, 매도 10단계는 청군 쪽에 계단으로 선다. **잔량이 두꺼운
단계일수록 벽이 높다** — 뚫기 어려운 호가가 실제로 두꺼운 벽으로 보인다.

절대 수량은 종목마다 자릿수가 다르므로 스무 단계 중 최대치를 1로 잡는다. 가격 간격
그대로 놓으면 열 단계가 한 점에 겹치므로 사다리처럼 편다. 사이드카로 매매가 멈추면
호가도 의미가 없어지므로 경계선과 함께 사라진다.

### 사이드카

원래 사이드카는 **KOSPI200 선물이 ±5%로 1분 지속**될 때 프로그램매매를 5분 멈추는
**지수 단위** 장치라 개별 종목에는 발동하지 않는다. 여기서는 단일 종목 화면이므로
**종목 자체가 2분 안에 ±3% 움직이면** 발동하도록 트리거만 바꿔 이름을 빌려 썼다.

발동하면 화면 중앙에 경보가 뜨고, 양 진영 병사가 전선을 버리고 자기 성 안으로 물러난다.
유지 시간은 실데이터에서 실제와 같은 5분, 목업에서는 관찰용으로 25초다.

## 화면 조작

- 드래그 회전 / 휠 줌
- 우하단 **시점 1 2 3** — 클릭하면 저장해 둔 시점으로 이동, `Shift`+클릭이면 지금
  화면을 그 칸에 저장한다. 빈 칸은 그냥 눌러도 저장된다 (브라우저에 남는다)
- 우하단 **크기** 슬라이더 — HUD 패널 배율
- 우하단 **♪** — 소리 켜기/끄기. 브라우저 정책상 한 번은 눌러야 소리가 난다
- 우하단 **숨기기** 버튼 또는 `H` 키 — HUD 전체 토글
- 좌하단 **함성** 입력창 — 한마디 쓰고 `Enter`. 관중 아무나가 그 말을 외친다.
  **보고 있는 모두의 화면에서** 외쳐진다 (한 사람당 2초 간격, 40자)
- 병사나 관중을 클릭하면 뜨는 **한마디** 입력창은 이 컴퓨터에서만 도는 미리보기다
- 목업일 때만 보이는 **DEV** — 현재가 고정, 상/하한가, 뉴스 발생, 배치 검산용 눈금

### 장 상태

우하단에 `KIS LIVE · 장중` 처럼 출처와 장 상태가 같이 뜬다. **장이 닫혀 있으면 값이
안 움직이는 게 정상**이라 이걸 보고 구분한다. 공휴일 달력은 없어서 주말만 `휴장`으로
잡고, 평일 휴장일은 `장전`으로 보인다.

## 튜닝

게임 감각은 [server.py](server.py) 상단 상수에서 전부 조절한다.

- `ARMY_SCALE` — 한 진영 총 병력 규모
- `UNIT_WEIGHT` — 유닛 1기가 대표하는 지분. 전형적 수급 구성(개인 55 / 외국인 22 /
  기관 15 / 연기금 8%)에서 네 병종이 모두 보이도록 잡혀 있다
- `SIDECAR_TRIGGER` / `SIDECAR_WINDOW_S` / `SIDECAR_HOLD_S`
